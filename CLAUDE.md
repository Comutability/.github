# Claude Code Rules for Comutability/.github

@AGENTS.md

This is a **public organisation profile/defaults** repository, not an app.

Before making edits, read the approved Comutability charter and this repository's AGENTS.md. Check the requested issue, intended profile/issue template change, and the central proposed COM-AI-001 AI rules. Only edit authorised files on a feature branch; provide a reviewable PR. Do not change membership, merge, deploy websites, disclose secrets or claim an unapproved policy is active.

Validate markdown links, YAML syntax for issue forms, accessibility and status accuracy. Report only tests actually run. All public guidance uses accessible UK English. GitHub's shared community-health files and individual agent instruction files have different inheritance behaviours: never claim the latter are automatic across all repositories.
