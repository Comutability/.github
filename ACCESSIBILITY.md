# Accessibility at Comutability
**Status: proposed guidance.**

Our mission includes tools that are understandable and usable by people of different abilities and technical backgrounds. We aim for keyboard navigation, clear labels and focus states, readable typography, sensible contrast and understandable help text where relevant.

**We do not claim universal WCAG compliance or independent accessibility certification.** Each project should document supported platforms, known barriers, actual testing and a named maintainer for accessibility decisions.

Please report accessibility problems in the relevant project repository, using non-sensitive examples, or propose an improvement in [Community issues](https://github.com/Comutability/Community/issues).

Contributions through screen-reader testing, keyboard testing, language simplification, translation and accessible design are welcome.
