# Getting Help
**Status: proposed organisation-wide support guide.**

- For a specific application, consult its README, documented release status and existing issues first.
- For community ideas, onboarding or questions, use [Community issues](https://github.com/Comutability/Community/issues).
- For a reproducible non-security bug, open an issue in the application's own repository, using the bug template and removing personal details.
- For **security vulnerabilities, use a private channel**; do not create a public issue containing exploit information.
- If a project is marked idea, discovery or prototype, it may have **no downloadable release or maintainer response commitment**.

Comutability is an emerging volunteer community. Support response times, when offered, depend on available human maintainers. Paid support, if introduced, will be described explicitly.
