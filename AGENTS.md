## Must
- Maintain accurate links, coherent Comutability names, UK English, accessible layouts and clear draft/approved states.
- Edit only authorised documentation/template files through an issue, feature branch and reviewable PR.
- Never publish credentials, security exploit details or personal data in shared issue templates, descriptions or profile pages.
- Explain that rules in this repository are **not automatically inherited by every AI tool or Base44 app**. Project repos need their own local instructions and external tool configuration.
- Show how public contributors can participate without automatically receiving GitHub organisation membership.
- Obtain named human approval for shared templates, live policies, security contacts and external website deployments.

## Must not
- Claim the founder has approved governance PRs without an explicit decision.
- Change the approved charter, separate product code, GitHub organisations or production websites here.
- Self-merge, self-release, self-authorise GitHub Apps, change organisation teams or grant privileged access.
- Claim unverified releases, independent security audits, proprietary AI model ownership or certified accessibility.

If scope is unclear or conflicting, stop and ask a human maintainer.
