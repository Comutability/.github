# Proposed Comutability Code of Conduct
**Status: draft; confidential reporting contact and appeal procedure must be established before adoption.**

We want a welcoming, accessible community for people with different technical backgrounds, languages and abilities.

## Expected behaviour

Be constructive and respectful. Challenge ideas without attacking people. Assume good intentions while remaining accountable for harm. Make technical discussions accessible to newcomers, respect privacy and give credit.

## Unacceptable behaviour

Harassment, threats, discrimination, stalking, deliberate disclosure of private details, intimidation, persistent personal attacks and knowingly unsafe publication of other people's data.

## Moderation and complaints

Human maintainers will address concerns proportionately, remove abusive content when needed and take action against repeated violations. Reports involving a maintainer require an impartial reviewer.

**No confidential conduct-reporting channel is yet confirmed. Do not post sensitive complaints or personal details in public GitHub issues.** The community must appoint reporting contacts, a confidential mechanism, an appeals process and retention limits before this code is approved and merged.

This proposed code is not a claim that a staffed moderation team already exists.
