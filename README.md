# Comutability organisation-wide GitHub files

This public `.github` repository contains [Comutability's profile](profile/README.md) and proposed default GitHub contributor guidance, bug/idea forms and PR templates.

**Source of truth:** [Community repository](https://github.com/Comutability/Community). Read the [approved Founding Charter](https://github.com/Comutability/Community/blob/main/FOUNDING-CHARTER.md) and the [unified operating handbook proposal](https://github.com/Comutability/Community/pull/5).

**Caution:** The shared templates and conduct/security guidance in this proposal branch are **drafts**. GitHub uses certain defaults across other repositories **only once they are merged to the default branch**. Do not ratify them before establishing a confidential reporting channel, human moderators and the community's governance process.

This repository is for organisation community-health information, **not app code**, **not secrets** and **not proprietary AI vendor source code**.

**Built together. Open to everyone.**


## AI agent rules (draft)

The organisation's canonical proposed rules are [COM-AI-001 in the Community Handbook PR #5](https://github.com/Comutability/Community/blob/proposal/unified-organisation-playbook-v0.1/policies/AI-AGENT-OPERATING-RULES.md). This repository also contains proposed local `AGENTS.md`, `CLAUDE.md` and `.github/copilot-instructions.md`. **Each accepted project must install and review its own instructions.** Rules here do not automatically enforce agent permissions or deployment controls.
